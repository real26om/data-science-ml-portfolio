# Residential Energy Consumption Analysis Using Python

## Objective

This project analyzes hourly residential energy consumption data to identify daily, weekly, and peak demand patterns.

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains hourly electricity consumption and weather-related variables.

## Main Steps

1. Loaded and inspected the dataset.
2. Cleaned missing values.
3. Created time-based features.
4. Analyzed hourly and weekly energy patterns.
5. Visualized peak demand periods.

## Key Results

- Peak demand usually occurred during evening hours.
- Weekday and weekend consumption patterns were different.
- Outdoor temperature showed a visible relationship with energy demand.
